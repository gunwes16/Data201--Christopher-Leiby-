## Inline Code & Code Block

When I log a catch, I record the fish type using a variable like `fish_type`.

Here's a small multi-line SQL code block:

```python
catches = [
    {"fish": "trout", "weight_lb": 1.2},
    {"fish": "bass", "weight_lb": 3.5},
    {"fish": "yellow perch", "weight_lb": 0.8}
]

for catch in catches:
    print(f"Caught a {catch['fish']} weighing {catch['weight_lb']} lbs")
​```
